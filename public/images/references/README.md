# Referans Logoları (Reference Logos)

Bu klasördeki dosyalar (`logo-01.svg` … `logo-14.svg`) **placeholder / yer tutucu**dur.
Gerçek referans firmalarınızın logoları ile değiştirilmesi gereklidir.

## Nasıl Değiştirilir?

Aynı isimde (`logo-01.png`, `logo-01.jpg` veya `logo-01.svg`) dosyaları bu klasöre kopyalayın
**ve** `lib/references-data.ts` dosyasındaki dizide karşılık gelen `image` yolunu güncelleyin.

### Önerilen Logo Özellikleri

- **Format**: SVG (tercih edilen) veya PNG (saydam arka plan)
- **Boyut**: ~220 × 80 px civarı (oranı korumak yeterlidir)
- **Renk**: Logoların orijinal renkleri kullanılabilir; site stilizesinde gri-ölçek
  görüntü için CSS filtreleri component içinde uygulanmıştır.

---

These files (`logo-01.svg` … `logo-14.svg`) are **placeholders**.
Replace them with the actual logos of your reference companies.

## How to replace

Drop new files with the same name into this folder (or update the `image` field in
`lib/references-data.ts` to point at a different filename).

Recommended size: ~220 × 80 px, SVG preferred, transparent background.
